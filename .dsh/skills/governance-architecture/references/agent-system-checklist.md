# AI Agent 系统专项检查清单

> 适用于具有规划、记忆、工具调用、自主执行、多 Agent 协作或长期任务能力的系统。
> 逐项回答「是 / 否 / 不适用」，并给出证据（仓库相对路径 + 符号名或测试用例）。

## 1. 权限与能力分离

- [ ] 计划权不等于执行权：模型提出计划不代表有权执行计划。
- [ ] 工具调用意图不等于执行授权；执行层独立执行必要的权限检查。
- [ ] 上下文中的指令不自动获得可信地位；检索内容、网页内容、工具返回值与外部文件按来源分级信任。
- [ ] 关键副作用在可信执行边界再次进行权威授权与验证。
- [ ] 不把提示词中的安全要求当作真正的权限隔离。

## 2. 状态与任务生命周期

- [ ] 任务状态与合法转换是显式模型（状态机或类型），不是大量互相矛盾的布尔变量。
- [ ] 成功、失败、取消、超时与待人工确认的终止条件明确。
- [ ] 不可逆副作用不会因重试或重复提交而执行两次；重复提交有幂等或去重机制。

## 3. 上下文与记忆

- [ ] 区分事实、推断、用户偏好、临时状态与未经验证的信息。
- [ ] 记忆有来源、更新条件、过期策略与冲突处理规则。
- [ ] 优先用结构化数据和明确来源降低歧义，而不是增加更多拦截规则。

## 4. 多 Agent 协作

- [ ] 每个 Agent 的职责、输入、输出与权限明确。
- [ ] 不默认其他 Agent 的结论具有权威性。
- [ ] 全局治理逻辑只实现一处；共享资源、任务交接与副作用有明确的所有权边界。
- [ ] 只在跨 Agent 信任边界确有需要时增加独立验证。

## 5. 自主执行

- [ ] 操作按风险分级，而不是对所有操作采用同等强度的守卫。
- [ ] 高影响、不可逆或超出授权范围的操作有审批或确认机制。
- [ ] 时间、调用次数、成本、资源与重试有明确预算和终止条件。
- [ ] 失败时进入明确的恢复或终止状态，而不是无限循环重试。
- [ ] 不把模型自我检查、自我承诺或再次生成答案当作独立安全边界。
