# 商用就绪清单

> 这是交付决策文档，不是营销材料。状态只有三种：**已具备 / 有条件具备 / 不具备**。
> 证据必须可复跑；不能在客户环境复现的项一律不算“已具备”。

## 1. 当前结论

| 场景 | 结论 |
|---|---|
| 内部演示 / UAT 环境 | **可以** |
| 单租户、自托管、管理员发放账号的正式生产 | **有条件具备**：完成 §4 的生产验收后可以 |
| 多租户 / 高可用 / MFA 强制 / 自助找回密码 | **不具备**（见 §3） |

## 2. 商用能力矩阵

| 维度 | 状态 | 证据 / 说明 |
|---|---|---|
| 登录、OIDC/OAuth、RBAC、审计、客户端管理 | 已具备 | 1545 项测试 + 24 条 E2E；CI 全绿 |
| 安全基线（JWT/撤销/限流/反提权/HSTS/安全头） | 已具备 | 安全 ADR、API 测试、Gateway 测试、`pnpm audit` 无已知漏洞 |
| 自托管部署脚本 | 已具备 | `deploy.sh` 校验/构建/迁移/健康/回滚；生产 Compose 校验通过 |
| 数据库备份 | 已具备 | `backup.sh`：dump + `pg_restore --list` + SHA-256 |
| 数据库恢复 | 有条件具备 | `restore.sh` 隔离库恢复 + 原子换名；已在验收栈演练，**客户生产环境未演练** |
| 升级前自动备份 | 已具备 | `deploy.sh` 调用 `backup.sh --if-running`，失败中止 |
| 健康检查 | 已具备 | Portal `/api/health` 检查 DB+Redis；Gateway `/healthz`；登录 200 作为业务就绪 |

| 告警 | 不具备 | 仓库无 Alertmanager/云监控配置；需交付团队接入 |
| 运维手册 | 已具备 | `docs/operations.md`：上线、备份恢复、监控、故障、验收 |
| CI 门禁 | 已具备 | Node/Gateway/ACME/验收全绿 |
| 真实 HTTPS / ACME | 有条件具备 | 代码与 staging 脚本具备；**真实域名首次签发未在本会话验证** |
| 单实例可用性 | 不具备 | 单 Gateway/Portal；无 HA/多副本/故障切换 |
| 日志保留 / 合规归档 | 有条件具备 | 容器日志轮转；审计分区维护需外部调度；audit/login 长期归档未实现 |
| 自助找回密码 | 不具备 | 仅管理员重置 + 已知旧密码修改（PRD 未来项） |
| MFA / Passkeys | 不具备 | PRD 未来项 |
| 会话并发上限 | 不具备 | NFR-SEC-16 backlog |
| 多租户 | 不具备 | 单租户设计 |
| 移动端完整体验 | 有条件具备 | 桌面优先；移动端保留部分适配，不承诺全功能 |

## 3. 商用阻断项（按优先级）

1. **生产环境验收**：真实域名 DNS、80/443、ACME 首签/续期、备份恢复、回滚、登录冒烟；
2. **外部监控告警**：接入 `/api/health`、Gateway metrics、容器重启、磁盘、证书到期、备份失败；
3. **客户数据迁移**：旧库 `pg_dump → PG18 → pg_restore`，并在客户环境做恢复演练；
4. **产品范围确认**：若客户要求自助找回、MFA、多租户、HA，以上均为新增项目，不在当前交付范围；
5. **安全评审/UAT**：渗透测试或客户安全评审、业务 UAT 签字。

## 4. 正式上线验收清单

- [ ] `.env.prod` 权限 600；`pnpm deploy -- --check` 通过；
- [ ] 首次部署后 `https://<domain>/login` 200，`/healthz` 200，`/api/health` 200；
- [ ] ACME 证书签发成功，重启后证书仍有效；
- [ ] 手动 `backup.sh` 成功，`restore.sh` 在验收库演练成功；
- [ ] `deploy.sh --rollback` 验证镜像回退；
- [ ] 外部监控接入并触发过一次测试告警；
- [ ] 备份定时任务 + 异地副本已配置；
- [ ] 交付版本 SHA、备份 SHA-256、验收记录归档；
- [ ] 已知边界（§2 不具备项）向客户书面确认。

## 5. 交付判定

只有 §4 全部打勾，才可标记“可商用交付”。当前代码基础已经达到**可进入生产验收的候选版本**，
但不是“开箱即商用”的成品；差距主要在**客户环境验收、外部监控、产品范围**，而不是测试通过率。
