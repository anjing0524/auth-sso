# Auth-SSO 产品 UI/UX 规范

> 版本 v1.0（2026-10-23）。本文是**产品与交互层**的单一真相源：任务模型、页面模板、交互规则、量化预算与逐页要求。
> 视觉 token 见 `docs/spec/DESIGN.md`（颜色/字体/圆角/动效）；架构规则见 `docs/spec/ARCHITECTURE.md` 与 `docs/adr/`。
> 任何页面改造必须先对照本文；出现冲突时，**产品任务目标优先于局部分工**，改动同步回本文。

---

## 1. 产品任务模型（先想"用户要干什么"）

| 用户角色 | 典型任务（JTBD） | 成功标准 |
|---|---|---|
| 超级管理员 | 建组织 → 建人 → 配角色/权限 → 接入应用 → 查审计 | 每个任务 ≤ 3 个页面、关键任务步骤可量化 |
| 部门管理员 | 管本部门用户/角色、查看本部门审计 | 只看到有权限的入口与数据（不靠猜） |
| 审计/安全 | 按人/时间/结果筛选登录与操作、导出证据 | 筛选 ≤ 2 次操作即可定位；导出带当前筛选 |
| 只读观察者 | 浏览配置、复制信息 | 所有写入口隐藏且直达解释，而非报错 |

**核心任务步骤预算（目标值，实测见 `UX-METRICS.md`）**

| 任务 | 目标 | 现状基线 |
|---|---|---|
| 新建用户 | ≤ 4 次输入 + 1 次提交 | 填写 5 字段 + 选择部门，弹窗内完成 |
| 给用户分配角色 | ≤ 2 次点击 + 保存 | 详情页 →「分配角色」页 → 勾选 → 保存 |
| 给角色配齐某应用权限 | 1 次组全选 + 保存（≤ 3 步） | 树/分组 + 组全选 + 保存 |
| 定位一条审计记录 | ≤ 2 个筛选 + 1 次搜索 | 页签 + 类型筛选（待补时间/结果筛选） |
| 注册 OAuth 应用 | 单页分组填写 + 1 次提交 | 应用表单页 |

设计判断顺序：**任务是否能在少于 N 步完成 → 关键信息是否一眼可见 → 视觉是否一致美观**。任何"看起来更好但多一步"的改动都需要理由。

## 2. 设计原则（按优先级）

1. **任务优先**：每个页面只回答一个问题（列表页=找并处理；详情页=看清并修改；分配页=批量授予）。
2. **一眼看到重点**：主信息（角色名/用户名/状态）占据视觉权重，辅助信息弱化且可截断；空态与错误态都给出下一步。
3. **少点击、少输入、少滚动**：能量化就量化；批量、搜索、过滤、默认值、快捷入口优先于逐项操作。
4. **可逆与确认**：破坏性操作必须有影响面（用户数/子权限数）；确认弹窗只用于轻确认，内容多就改页面。
5. **一致**：同一层级的字号/间距/控件高度/图标/术语只有一个口径（见 §4、§6）。
6. **反馈**：任何异步操作 ≤ 100ms 有视觉响应（loading/disabled），成功 toast、失败就地说明。
7. **无障碍**：键盘可达、焦点可见、label 关联、对比度 ≥ 4.5:1、图标按钮必须有 `aria-label` + `title`。
8. **无装饰性噪音**：后台不用无意义渐变/发光/大插图；阴影只用于层级（卡片/浮层）。

## 3. 页面模板

### 3.1 列表页（List）
```
[顶栏 48px：折叠 · 面包屑 · ⌘K]
[卡片工具栏 40-44px：h1(15px) · 搜索 · 筛选 · 计数 · 主操作]
[表头 32px] [数据行 40-48px，内部滚动，表头吸顶]
[分页 36px：共 N 条 · 翻页(单页隐藏)]
```
- 标题并入工具条（不再独立大页头）；工具栏内控件统一 **32px**。
- 表格：`h-10` 行高、`px-3 py-1.5`、表头 11px medium；主信息 13px semibold + 次要信息 11px。
- 行操作：≤3 个图标按钮（`aria-label`）；页面跳转类操作用链接而不是弹窗。
- 空态分两类：无数据（引导创建）/ 筛选无结果（清除筛选），都保留工具栏。
- 支持批量时：表头/首列 checkbox + 选中计数 + 批量操作条（仅当前页范围，明示范围）。

### 3.2 详情页（Detail）
- `PageHeader`：返回 + `type-page-title`(17px) + 一行辅助信息 + 右侧主操作（32px）。
- 内容分组卡片（`type-card-title`），只读态用 banner 明示原因并禁用控件。
- 危险操作与主操作分离（左下/次要按钮）。

### 3.3 表单页（Form）
- 分组（基本信息 / 菜单配置 / 安全设置）而不是一长列；两列栅格（`sm:grid-cols-2`）。
- 底部主操作固定可见；校验就地显示；提交中禁用并显示进度文案。
- **禁止把多字段表单塞进弹窗**（600px 视口高度放不下就必须页面）。

### 3.4 分配/授权页（Assignment）
```
[页头：返回 · 标题 · 已选统计 · 保存(固定)]
[左：作用域树（应用 / 菜单目录）  右：作用域内权限列表]
[右工具栏：搜索 · 全选本作用域 · 仅看已选]
[清单：分组头 checkbox + 子项；深度缩进；点击即勾选]
```
- 作用域树：接口按**应用**分组；页面/目录按**父子树**（可折叠、搜索自动展开）。
- 级联：父节点全选 = 其全部后代；部分选中显示"已选 x/y"。
- 支持"全部/已选"视图、全选所有、清空；保存一次生效。
- 必须支持键盘与移动端（窄屏树折叠为 Select）。

### 3.5 调查/审计页（Investigation）
- 筛选在 URL 中（页签、类型、时间范围、结果、关键字），刷新/分享/后退保持。
- 表格列按"时间 → 谁 → 做了什么 → 结果 → 上下文"排序；时间用相对+绝对（hover/title 显示精确值）。
- 详情用侧滑面板或页面（若超出轻量信息），避免在表格里塞大段 JSON。

### 3.6 工作台（Dashboard）
- 首屏三块：待办/引导任务（可直接跳转）、关键指标（用户/角色/应用/近 7 日登录）、最近动态。
- 数字可点击进入对应列表（筛选态），不做纯装饰图表。

## 4. 量化预算（每次页面改动都要过）

| 指标 | 预算 | 验证方式 |
|---|---|---|
| 页面级滚动条 | **0**（登录页含；600px 高视口） | Playwright：`scrollHeight > innerHeight` |
| 首数据行距顶（chrome） | ≥800h：≤20%；600h：≤30% | 量 `tbody tr` top / innerHeight |
| 列表可见行 | 600h ≥ 8 行；800h ≥ 14 行 | 量完整可见行数 |
| 控件高度 | 工具栏 32px；表单 36px；触控目标 ≥32px | 量 `getBoundingClientRect().height` |
| 弹窗 | **不得滚动**；超出视口 = 改页面 | 600/700h 下量 dialog rect + overflow |
| 字体层级 | 只用 §6 的 6 个 token | 源码/样式断言 |
| 页面横向滚动 | 390px 下为 0 | `scrollWidth > innerWidth` |
| 文本对比度 | ≥4.5:1（状态徽章文字用 token） | 抽查 |
| 动效 | 100–200ms，`ease-out`；只用于出现/状态变化 | 抽查 |
| 任务步骤 | 见 §1 预算 | 手工/脚本计数 |

测量脚本：`node scripts/ux/measure.mjs`（需要验收栈 `https://127.0.0.1:19443` 已启动）。
结果写入 `docs/spec/UX-METRICS.md`（版本化基线，改动前后对比）。

## 5. 交互规则

- **搜索**：300ms 防抖；输入即时回显、查询异步；`Esc` 清空；同步 URL（`keyword`）并重置 `page=1`；显示结果计数；busy 时输入框内转圈。
- **筛选**：全部进 URL；有筛选时显示已选条件 chip 与"清除"；不改变列排序心智。
- **批量**：明确范围（当前页/当前筛选/当前作用域）；组头全选 + 组内已选计数；批量操作前显示影响数量；危险批量二次确认。
- **分页**：每页 20 行；单页隐藏翻页控件；保留总数；跳页越界 clamp 并给可见提示。
- **危险操作**：必须显示影响面（用户数、子权限数、下游影响），不使用原生 `confirm`。
- **异步**：提交期间按钮 disabled + 文案"处理中…"；失败就地显示字段错误或 toast；不允许静默失败。
- **键盘**：Tab 顺序与视觉一致；焦点环 ≥2px；所有图标按钮有可读名称；列表支持 Enter 进入详情。
- **文案**：中文优先；枚举值必须映射为业务语言（不得直接显示 `API/PAGE/LOCKED` 等代码）；数字用 `tabular-nums`。

## 6. 视觉/美学系统

- **字体层级（唯一）**：`.type-page-title` 17/24·600｜`.type-section-title` 15/22·600｜`.type-card-title` 13/20·600｜`.type-body` 13/20｜`.type-meta` 11/16｜`.type-table-head` 11/16·500。页面禁止自写字号（图标尺寸除外）。
- **间距**：4px 网格；页面级 `gap-3`(12)、卡片内 `p-3`(12~16)、单元格 `px-3 py-1.5`、分组之间 12–16；同类元素间距必须一致。
- **圆角**：卡片 8px、控件 8px、徽章 4–6px、浮层 12px；同一组件不混用。
- **边框/阴影**：1px `border-border/70`；卡片阴影只用于浮起层级（`shadow-sm`）；不要用 `ring-border` 当描边（会解析成 currentColor 黑边）。
- **图标**：行内 14/16px，工具栏 16px，页头 16px；同一语义用同一图标。
- **状态色**：成功/警告/危险/信息只用 token 徽章；不要用纯色大块背景。
- **动效**：仅用于 hover 反馈与出现/消失；禁止无限循环动画（loading 除外）。
- **信息密度**：列表页优先信息密度，详情页优先可读性；空态不占满整屏（卡片贴合内容）。

## 7. 无障碍与响应式

- 断点：390（手机）/768（平板）/1024（小桌面）/1440+（桌面）；列表在 <1024 隐藏次要列，操作列始终可见或可横向滚动（表头吸顶）。
- 登录/表单在 390×844、1139×600 均无页面级滚动；内容过多时页面滚动是允许的（但表单页操作按钮应跟随内容末尾或固定在视口内）。
- 所有交互元素可见焦点；跳转到主内容的 skip-link；表单 label 关联；错误信息 `aria-invalid` + 关联说明。
- 颜色不是唯一信息载体（状态徽章带文字）。

## 8. 逐页要求矩阵（审计用）

| 路由 | 任务 | 关键信息 | 必须支持 | 当前缺口 |
|---|---|---|---|---|
| `/login` | 登录 | 身份/错误原因 | 600/390 无滚动、错误可读、自动填充 | 已修；可加"忘记密码"入口（若产品支持） |
| `/dashboard` | 知道下一步做什么 | 引导任务、指标、动态 | 指标可点击、近 7 日登录、最近操作、快捷入口 | ✅ 指标整卡可点 + 真实登录聚合（**失败数直达失败登录**）+ 最近操作 + 快捷动作 |
| `/users` | 找人并处理 | 姓名/邮箱/部门/状态 | 搜索+状态+部门筛选、分配角色入口、批量 | ✅ 搜索/状态/部门筛选 + **多选批量禁用/恢复（含影响确认）** |
| `/users/[id]` | 看人/改人 | 基本资料、角色、安全 | 只读模式、重置密码、解锁 | ✅ section 化 + **角色直接可见（含未分配语义）** + 最近登录/邮箱验证 |
| `/users/[id]/roles` | 分配角色 | 可选角色/已选 | 搜索、组全选、保存 | ✅ 搜索 + 全选当前筛选/清空/仅看已选 + 待新增/待移除差异 + 保存确认 |
| `/roles` | 管理角色 | 名称/编码/部门/状态 | 搜索、删除影响面、权限入口 | ✅ 密度重做 + **权限数列（0 项=空壳角色可见，点击进配置）** |
| `/roles/[id]/permissions` | 批量授权 | 作用域树/清单/已选 | 树+过滤+级联+全选/清空 | ✅ 作用域树 + 分组 + 状态过滤 + 仅看已选/变更 + 差异确认 + **常用权限模板一键套用** |
| `/permissions` | 管理权限点 | 名称/编码/类型/状态 | 类型页签、搜索、编辑入口 | 新建/编辑已页面化；缺批量删除 |
| `/permissions/new` `/…/edit` | 建/改权限点 | 8 字段分组 | 两列、校验、返回 | 已页面化 |
| `/departments` | 组织维护 | 树、成员、状态 | 展开/收起、搜索保祖先、移动校验 | ✅ 标题并入工具条 + 直属成员数 + 行密度收紧 + **多选批量移动（循环/越权逐项校验）** |
| `/clients` | 接入应用 | Client ID/回调/状态 | 搜索、注册入口、注销影响 | 缺"最近使用"/排序 |
| `/clients/new` | 配置应用 | 回调/密钥/权限 | 三分组、scope/TTL 预设、Secret 一次性展示、固定提交 | ✅ 已按 §3.3 落地 |
| `/audit-logs` | 调查取证 | 时间/人/事件/结果 | 类型+时间+结果筛选、导出当前筛选 | ✅ 预置/自定义日期 + 事件类型 + 搜索 + 导出沿用 + **筛选 chips（可单个移除/清空）** |
| `/profile` | 自助资料/安全 | 资料、密码、会话 | 保存反馈、密码强度 | ✅ 紧凑身份头 + 账户资料/权限摘要/登录会话（默认 3 条，可**逐个撤销**） |

## 9. 设计债与优先级

> **视觉一致性守卫**（2026-10-26 起）：`crud-f7-guards.test.ts` 扫描 `src/app/**/*.tsx`，
> 禁止 `ring-1 ring-border*`（会解析成 currentColor 黑描边）、`uppercase tracking-wider/widest`
> （中文散字）、`font-black`（与字重体系冲突）；残留 = 测试红。

1. **P0**：权限分配树/过滤（本轮）、用户批量操作、审计时间/结果筛选。
2. **P1**：应用配置表单分组、详情页 section 统一、工作台指标接真实数据。
3. **P2**：动效/微交互统一、空态插画克制化、暗色模式对比度复核。

> 每次改动后更新 `UX-METRICS.md` 的基线与本节状态；规范随产品演进（新增页面必须有对应模板）。
