# docs/archive 归档索引

> **定位**：这里放**历史工作产物**（审计报告、实施计划、已被取代的旧规范）。
> **不作为现行规范引用** —— 现行约定见根 `AGENTS.md` / `CODING_STANDARDS.md` / `docs/adr/` /
> `docs/solution/`。归档的意义是保留"当时怎么想的"以便追溯，而不是指导今天的做法。

## 为什么有归档（而不是直接删）

本仓的取舍：**历史产物能解释"为什么长这样"就值得留**，但留在 `docs/` 顶层会稀释现行文档。
因此统一 `git mv` 到此（保留逐文件历史）。迁移时**同步修正了跨文档的路径引用**（兜底 grep 确认无裸引用）；
**归档目录内部的相对链接**是另一类问题（`../` 相对深度会变），已于 2026-10-19 逐条校正。
